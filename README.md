## 🤖 Bots de IA para redes

| Bot | Qué hace |
|---|---|
| 💬 **Asistente de WhatsApp** | Responde consultas 24/7 con IA, sabe de los servicios y productos del negocio, y deriva a una persona cuando hace falta. Pausa el bot cuando el dueño contesta a mano. |
| 📸 **Asistente de Instagram** | Contesta DMs y comentarios (respuesta pública + mensaje privado), detecta qué producto le interesa al cliente y avisa por WhatsApp al responsable. Renueva su token solo. |
| 🎬 **Generador de contenido** | Arma posts, carruseles y reels para Instagram con la voz de la marca, listos para revisar y publicar. |

Hechos con **Claude (Anthropic)**, Node.js y Cloudflare Workers + D1. Se configuran por cliente: cada negocio tiene su propio asistente.
